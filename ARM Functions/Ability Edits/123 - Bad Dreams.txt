Ability: Bad Dreams (ID: 123)
==================================================

Effect:
Damages sleeping opponents for 1/8 their max HP after each turn.

Dynamic ARM Mechanic:
- **Fractional Math (Healing):** The ARM code loads the Max HP from the Pokémon's stat struct. It then uses a logical shift right (`lsr`) instruction (`lsr #4` for 1/16th, `lsr #3` for 1/8th) to efficiently divide the Max HP by a power of 2.
- **Subroutine:** It calls the global healing subroutine (`bl`), passing the shifted value as the heal amount.
- **Status Affliction/Check:** The code loads the specific bitflag representing the status condition (e.g., `0x8` for Poison, `0x10` for Burn) into a register. It either bitwise-ANDs (`and`) it to check for the status, or bitwise-ORs (`orr`) it into the target's volatile status memory block to inflict it.
