Ability: Triage (ID: 205)
==================================================

Effect:
This Pokémon's healing moves have their priority increased by 3.

Dynamic ARM Mechanic:
- **Fractional Math (Healing):** The ARM code loads the Max HP from the Pokémon's stat struct. It then uses a logical shift right (`lsr`) instruction (`lsr #4` for 1/16th, `lsr #3` for 1/8th) to efficiently divide the Max HP by a power of 2.
- **Subroutine:** It calls the global healing subroutine (`bl`), passing the shifted value as the heal amount.
- **Priority Tier Check/Override:** The code reads the priority integer from the move struct. It may compare it (`cmp rX, #0`) to see if it's a priority move, or use an `add` instruction to artificially increase the priority integer before execution order is sorted.

Execution Hooks:
--------------------
Address: 0x00043FFC (THUMB)
Raw Assembly:
0x43FFC: CD2F      cmp	r7, #0xcd
0x43FFE: 01EB0000  add.w	r0, r1, r0
0x44002: 50E3      b	#0x446a6
0x44004: 00F020E3  blx	#0x444648
0x44008: 0F00      movs	r7, r1

Logic Translation:
- `0x43FFC`: Compares the loaded ability ID against 0xcd. (Multiple cmp instructions in a row mean the engine is checking if the Pokémon has one of several abilities that share the exact same mechanic, like Mold Breaker/Teravolt/Turboblaze).
- `0x43FFE`: Adds `r0, r1, r0` to calculate the modifier.
- `0x44002`: Executes `b #0x446a6`.
- `0x44004`: Calls the engine subroutine at `#0x444648` to commit the math.
- `0x44008`: Loads literal `r1` into `r7`.
