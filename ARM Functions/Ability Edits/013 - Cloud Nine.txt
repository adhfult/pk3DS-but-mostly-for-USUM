Ability: Cloud Nine (ID: 13)
==================================================

Effect:
Negates all effects of weather, but does not prevent the weather itself.

Dynamic ARM Mechanic:
- **Weather Check:** The code reads the global battle state struct and compares the active Weather ID byte (`cmp rX, #WeatherID`). If the weather doesn't match the required state, it uses a `bne` (branch if not equal) to skip the effect.
