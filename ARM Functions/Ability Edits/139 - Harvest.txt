Ability: Harvest (ID: 139)
==================================================

Effect:
Has a 50% chance of restoring a used Berry after each turn if the Pokémon has held no items in the meantime.

Dynamic ARM Mechanic:
- **Multiplier Injection:** The engine loads the fixed-point hex value `0x1800` (which is 1.5x in 4096-based fixed-point math) into a register.
- **Calculation:** It then multiplies the base damage/stat by this register using `mul`.
- **Item Hook:** The logic hooks into the item consumption/removal subroutines. It compares the held item ID against known item index ranges (e.g., the Berry IDs) to determine if the effect should trigger.
