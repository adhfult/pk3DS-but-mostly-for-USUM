Ability: Ice Body (ID: 115)
==================================================

Effect:
Heals for 1/16 max HP after each turn during hail.  Protects against hail damage.

Dynamic ARM Mechanic:
- **Fractional Math (Healing):** The ARM code loads the Max HP from the Pokémon's stat struct. It then uses a logical shift right (`lsr`) instruction (`lsr #4` for 1/16th, `lsr #3` for 1/8th) to efficiently divide the Max HP by a power of 2.
- **Subroutine:** It calls the global healing subroutine (`bl`), passing the shifted value as the heal amount.
- **Weather Check:** The code reads the global battle state struct and compares the active Weather ID byte (`cmp rX, #WeatherID`). If the weather doesn't match the required state, it uses a `bne` (branch if not equal) to skip the effect.
- **Immunity Bypass:** The code sets a global immunity flag in memory (`str rX, [rY]`) OR it executes a branch (`b` or `beq`) that literally jumps completely over the damage/status calculation subroutine, thereby preventing the effect from occurring.
