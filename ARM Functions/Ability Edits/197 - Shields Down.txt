Ability: Shields Down (ID: 197)
==================================================

Effect:
Transforms this Minior between Core Form and Meteor Form.  Prevents major status ailments and drowsiness while in Meteor Form.

Dynamic ARM Mechanic:
- **Status Affliction/Check:** The code loads the specific bitflag representing the status condition (e.g., `0x8` for Poison, `0x10` for Burn) into a register. It either bitwise-ANDs (`and`) it to check for the status, or bitwise-ORs (`orr`) it into the target's volatile status memory block to inflict it.
- **Immunity Bypass:** The code sets a global immunity flag in memory (`str rX, [rY]`) OR it executes a branch (`b` or `beq`) that literally jumps completely over the damage/status calculation subroutine, thereby preventing the effect from occurring.
- **Form ID Override:** The engine writes a new integer to the Form ID byte in the Pokémon's data struct and triggers the form-change visual subroutine to update its model and stats.
