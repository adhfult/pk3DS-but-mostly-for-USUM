Ability: Rough Skin (ID: 24)
==================================================

Effect:
Damages attacking Pokémon for 1/8 their max HP on contact.

Dynamic ARM Mechanic:
- **Fractional Math (Healing):** The ARM code loads the Max HP from the Pokémon's stat struct. It then uses a logical shift right (`lsr`) instruction (`lsr #4` for 1/16th, `lsr #3` for 1/8th) to efficiently divide the Max HP by a power of 2.
- **Subroutine:** It calls the global healing subroutine (`bl`), passing the shifted value as the heal amount.
- **Contact Flag Check:** Before applying the effect, the code loads the move data struct of the incoming attack and performs a bitwise check (`tst` or `and`) against the 'Makes Contact' bitflag. If the flag is 0, it skips the effect.

- `0x1583C`: Compares the loaded ability ID against 0x18. (Multiple cmp instructions in a row mean the engine is checking if the Pokémon has one of several abilities that share the exact same mechanic, like Mold Breaker/Teravolt/Turboblaze).
