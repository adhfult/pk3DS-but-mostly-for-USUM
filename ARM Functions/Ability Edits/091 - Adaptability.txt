Ability: Adaptability (ID: 91)
==================================================

Effect:
Increases the same-type attack bonus from 1.5× to 2×.

- **Calculation:** It then multiplies the base damage/stat by this register using `mul`.
- **Positive Stat Modifier:** The code loads a positive integer (e.g., `mov rX, #1` or `#2`) for the stat stage increase and calls the modifier subroutine to boost the target's stat array.
- **Gender Comparison:** The code loads the gender byte (0=Male, 1=Female, 2=Genderless) of both the user and the target, compares them (`cmp`), and branches appropriately if they match or differ.
