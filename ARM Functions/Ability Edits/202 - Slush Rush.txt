Ability: Slush Rush (ID: 202)
==================================================

Effect:
During Hail, this Pokémon has double Speed.

Dynamic ARM Mechanic:
- **Weather Check:** The code reads the global battle state struct and compares the active Weather ID byte (`cmp rX, #WeatherID`). If the weather doesn't match the required state, it uses a `bne` (branch if not equal) to skip the effect.

Execution Hooks:
--------------------
Address: 0x000F5628 (THUMB)
Raw Assembly:
0xF5628: CA2C      cmp	r4, #0xca

Logic Translation:
- `0xF5628`: Compares the loaded ability ID against 0xca. (Multiple cmp instructions in a row mean the engine is checking if the Pokémon has one of several abilities that share the exact same mechanic, like Mold Breaker/Teravolt/Turboblaze).
--------------------
