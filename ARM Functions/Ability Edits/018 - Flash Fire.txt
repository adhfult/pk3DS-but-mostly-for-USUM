Ability: Flash Fire (ID: 18)
==================================================

Effect:
Protects against Fire moves.  Once one has been blocked, the Pokémon's own Fire moves inflict 1.5× damage until it leaves battle.

Dynamic ARM Mechanic:
- **Multiplier Injection:** The engine loads the fixed-point hex value `0x1800` (which is 1.5x in 4096-based fixed-point math) into a register.
- **Calculation:** It then multiplies the base damage/stat by this register using `mul`.
- **Immunity Bypass:** The code sets a global immunity flag in memory (`str rX, [rY]`) OR it executes a branch (`b` or `beq`) that literally jumps completely over the damage/status calculation subroutine, thereby preventing the effect from occurring.
