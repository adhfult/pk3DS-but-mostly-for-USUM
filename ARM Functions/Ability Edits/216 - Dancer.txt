Ability: Dancer (ID: 216)
==================================================

Effect:
Whenever another Pokémon uses a dance move, this Pokémon will use the same move immediately afterwards.

Dynamic ARM Mechanic:
- **Gender Comparison:** The code loads the gender byte (0=Male, 1=Female, 2=Genderless) of both the user and the target, compares them (`cmp`), and branches appropriately if they match or differ.

Execution Hooks:
--------------------
Address: 0x00046B4C (THUMB)
Raw Assembly:
0x46B4C: D82F      cmp	r7, #0xd8
0x46B4E: 01EB0010  add.w	r0, r1, r0, lsl #4
0x46B52: A0E1      b	#0x46e96
0x46B54: 0430      adds	r0, #4
0x46B56: 8DE2      b	#0x47074

Logic Translation:
- `0x46B4C`: Compares the loaded ability ID against 0xd8. (Multiple cmp instructions in a row mean the engine is checking if the Pokémon has one of several abilities that share the exact same mechanic, like Mold Breaker/Teravolt/Turboblaze).
- `0x46B4E`: Adds `r0, r1, r0, lsl #4` to calculate the modifier.
- `0x46B52`: Executes `b #0x46e96`.
- `0x46B54`: Adds `r0, #4` to calculate the modifier.
- `0x46B56`: Executes `b #0x47074`.
