Ability: Pickpocket (ID: 124)
==================================================

Effect:
Steals attacking Pokémon's held items on contact.

Dynamic ARM Mechanic:
- **Contact Flag Check:** Before applying the effect, the code loads the move data struct of the incoming attack and performs a bitwise check (`tst` or `and`) against the 'Makes Contact' bitflag. If the flag is 0, it skips the effect.
- **Item Hook:** The logic hooks into the item consumption/removal subroutines. It compares the held item ID against known item index ranges (e.g., the Berry IDs) to determine if the effect should trigger.
