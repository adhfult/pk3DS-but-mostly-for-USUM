Ability: Power Construct (ID: 211)
==================================================

Effect:
Transforms 10% or 50% Zygarde into Complete Forme when its HP is below 50%.

Dynamic ARM Mechanic:
- **Multiplier Injection:** The engine loads the fixed-point hex value `0x1800` (which is 1.5x in 4096-based fixed-point math) into a register.
- **Calculation:** It then multiplies the base damage/stat by this register using `mul`.
- **Form ID Override:** The engine writes a new integer to the Form ID byte in the Pokémon's data struct and triggers the form-change visual subroutine to update its model and stats.

Logic Translation:
- `0x42CD8`: Compares the loaded ability ID against 0xd3. (Multiple cmp instructions in a row mean the engine is checking if the Pokémon has one of several abilities that share the exact same mechanic, like Mold Breaker/Teravolt/Turboblaze).

- `0x42CE0`: Loads memory data into `r0`.
- `0x42CE4`: Stores `r1` into memory.
