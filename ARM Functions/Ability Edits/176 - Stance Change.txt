Ability: Stance Change (ID: 176)
==================================================

Effect:
Changes Aegislash to Blade Forme before using a damaging move, or Shield Forme before using King’s Shield.

Dynamic ARM Mechanic:
- **Form ID Override:** The engine writes a new integer to the Form ID byte in the Pokémon's data struct and triggers the form-change visual subroutine to update its model and stats.

Execution Hooks:

0x2AE0C: B00050E3  cmp	r0, #0xb0

0x2AE14: 0560A0E1  mov	r6, r5
0x2AE18: 0050A0E3  mov	r5, #0

Logic Translation:
- `0x2AE0C`: Compares the loaded ability ID against 0xb0. (Multiple cmp instructions in a row mean the engine is checking if the Pokémon has one of several abilities that share the exact same mechanic, like Mold Breaker/Teravolt/Turboblaze).
- `0x2AE10`: If it doesn't match, branches to `0x0x2ab30`.
- `0x2AE14`: Loads literal `r5` into `r6`.
- `0x2AE18`: Loads literal `#0` into `r5`.
