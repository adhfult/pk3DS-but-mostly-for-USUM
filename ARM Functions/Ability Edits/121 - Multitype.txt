Ability: Multitype (ID: 121)
==================================================

Effect:
Changes Arceus's type and form to match its held Plate.

Dynamic ARM Mechanic:
- **Elemental Type Override:** The code loads the hex ID of the specific elemental type (e.g., `0x0` for Normal, `0x2` for Flying) and overwrites the Type 1 / Type 2 bytes in the active Pokémon's battle struct, temporarily changing its typing.
- **Form ID Override:** The engine writes a new integer to the Form ID byte in the Pokémon's data struct and triggers the form-change visual subroutine to update its model and stats.
