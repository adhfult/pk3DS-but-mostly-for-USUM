Ability: Infiltrator (ID: 151)
==================================================

Effect:
Bypasses Light Screen, Reflect, and Safeguard.

Dynamic ARM Mechanic:
- **Weight Calculation:** The code reads the base weight integer from the species struct and uses it dynamically in the damage formula calculations (via division or multiplication).

Execution Hooks:
--------------------
Address: 0x00042E48 (THUMB)
Raw Assembly:
0x42E48: 972D      cmp	r5, #0x97
0x42E4A: 01EB0140  add.w	r0, r1, r1, lsl #16
0x42E4E: 84E2      b	#0x4335a
0x42E50: 0600      movs	r6, r0
0x42E52: 54E3      b	#0x434fe

Logic Translation:
- `0x42E48`: Compares the loaded ability ID against 0x97. (Multiple cmp instructions in a row mean the engine is checking if the Pokémon has one of several abilities that share the exact same mechanic, like Mold Breaker/Teravolt/Turboblaze).
- `0x42E4A`: Adds `r0, r1, r1, lsl #16` to calculate the modifier.
- `0x42E4E`: Executes `b #0x4335a`.
- `0x42E50`: Loads literal `r0` into `r6`.
- `0x42E52`: Executes `b #0x434fe`.
